Renders any of the 51 customer / partner marks extracted from the Brand Repository, by name.

```jsx
<CompanyIcon name="MetalsProperty1Tata" size={64} />
<CompanyIcon name="ConsumerGoodsProperty1Cocacola" size={48} />
```

Read `CompanyIcon.d.ts` for the full name list — names come from Figma layer names
(`<Sector>Property1<Company>`). Single-colour marks paint with `currentColor`.
These are third-party trademarks; use them only where their owners permit.
